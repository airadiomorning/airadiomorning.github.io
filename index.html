AIラジオ投稿ツール（ai-radio）

このサイトは、YouTubeチャンネル「AIラジオ - 朝のニュース解説」の運営者本人が使用する、動画投稿支援ツールの案内ページです。

ツールの機能

AIラジオ投稿ツールは、運営者本人が生成した動画ファイル（タイトル・概要・サムネイル・字幕）を、YouTube Data API v3 を使って運営者本人のYouTubeチャンネルへ投稿するための個人用ツールです。一般公開はしておらず、利用者は運営者本人1名のみです。

Googleユーザーデータの利用について

本ツールは、YouTubeへの動画投稿に必要な範囲でのみ Google アカウントの認可（OAuth）を使用します。取り扱いの詳細はプライバシーポリシーをご覧ください。
