プライバシーポリシー

AIラジオ投稿ツール（以下「本ツール」）は、YouTubeチャンネル「AIラジオ - 朝のニュース解説」の運営者本人が、自身のチャンネルへ動画を投稿するために使用する個人用ツールです。本ポリシーは、本ツールが Google ユーザーデータをどのように扱うかを説明します。

アクセスするデータ

本ツールは、YouTube Data API v3 の次のスコープで認可を受けます。

  • https://www.googleapis.com/auth/youtube.upload（動画とサムネイルの投稿）
  • https://www.googleapis.com/auth/youtube.force-ssl（字幕の投稿と、投稿した動画の状態確認）

これら以外の Google ユーザーデータ（メール本文、連絡先、ファイル等）にはアクセスしません。

データの利用目的

取得した認可情報は、運営者本人のYouTubeチャンネルへの動画・サムネイル・字幕の投稿と、投稿結果の確認のためにのみ使用します。

データの保存

OAuth のリフレッシュトークンは、運営者の管理する実行環境内の限定された領域（アクセス権限 0600 のファイル）にのみ保存します。サーバーへの送信、第三者への提供、販売は行いません。

限定使用（Limited Use）について

本ツールによる Google API から取得した情報の使用および他アプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含みます）を遵守します。取得したデータを販売したり、広告目的で使用したりすることはありません。また、本ツールは YouTube 利用規約 と Google プライバシーポリシー を遵守して利用します。

データの削除・認可の取り消し

認可は、Google アカウントの「サードパーティ製のアプリとサービス」設定からいつでも取り消すことができます。取り消した場合、本ツールはチャンネルへアクセスできなくなります。保存されたトークンの削除を希望する場合は、下記連絡先までご連絡ください。
